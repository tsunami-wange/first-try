# 个人主页与作品集

纯静态网站，无需安装依赖或构建。可直接双击 `index.html` 在浏览器中预览；也可在此文件夹打开终端，运行 `python3 -m http.server 8000`，再访问 http://localhost:8000/ 。按 Ctrl+C 停止服务。

## 修改内容

- `index.html`：首页文字、项目入口、经历、研究、关于与联系。
- `projects/`：四个项目详情页面；用文本编辑器打开对应 HTML 修改内容。
- `assets/style.css`：颜色、排版及响应式样式；颜色集中在文件开头。
- `assets/main.js`：为未来交互预留。
- `.nojekyll`：让 GitHub Pages 直接提供静态文件。

请补充姓名、教育信息、邮箱及真实联系链接，并确认适合公开的简历文件后再添加下载入口。项目图片、论文正式标题、研究图表与结论、Pair Go 原型等均待提供。占位区域是文字与色块，并非真实项目照片。添加真实图片时请提供描述性 alt 文本；为真实图片添加 data-zoom 和 tabindex="0" 属性即可启用点击或键盘放大；当前占位区域不冒充图片。新增项目时，可复制一份详情页，修改内容及前后项目链接，并在首页添加卡片。

将这些文件上传到 GitHub 仓库后，可在仓库 Settings → Pages 中选择从对应分支发布。所有内部路径均为相对路径。请先确认简历与个人信息适合公开；项目目录中现有 PDF 不会自动出现在网站链接中，但上传整个目录会一并公开这些文件。
